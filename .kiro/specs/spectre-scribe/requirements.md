# Requirements

1. Accept a user-supplied sample passage and compute style statistics (sentence length, vocabulary, dialogue ratio, pacing markers).
2. Generate a story bible: characters, timeline, world rules, foreshadowing list.
3. Outline, style, continuation and continuity agents work in relay, one chapter at a time.
4. Before a chapter is accepted, the continuity agent checks: no dead character reappears, timeline order holds, planted foreshadowing is either kept open or paid off.
5. Demo output: a 3-chapter science-fiction short story. The exact plot is not fixed in this scaffold.
